むん先生の学習クエスト  更新 1110e（サイト全体の機能）
=====================================================
このZIPの中身を、サイトのフォルダにそのまま上書きしてください。
（学習の記録は子どもの端末の中にあり、この更新では消えません）

【新しく入るファイル】
 404.html         見つからないページの案内（検索ボックスと人気アプリ付き）
 search.html / search-index.json   サイト内検索（端末の中だけで動きます。外には送りません）
 otona.html       「保護者・先生の方へ」入口ページ
 check.html       動作チェック（結果は印刷できます）
 offline.html     オフライン用にまとめて保存（先生が学年ごとに保存）
 feed.xml         更新情報のフィード
 _headers         安全・速度の設定（下の注意を読んでください）
 ogp.png          共有したときの画像
 theme.js / theme.css   ライト表示の切りかえ
 sw.js            オフライン用の仕組み（新しくなっています）
 tool/            sitemap_lastmod.bat・feed_koushin.bat（下を参照）

【書きかわるファイル】
 index.html koushin.html sitemap.xml と、guide/ lab/ などの各ページ
 （共有画像と、ライト表示の読み込みが入りました）

【注意】
 1. _headers は Cloudflare Pages / Netlify で効きます。Vercel では無視されます。
    また「他のサイトに埋め込む」ことを禁止する設定が入っています。
    Googleサイトなどにこのサイトを埋め込んでいる場合は、_headers の
    X-Frame-Options の行を消してください。
 2. ライト表示の切りかえは、このZIPで作っているページ（トップ・学習ガイド・むんラボ・案内ページ）に入ります。
    先生が別に管理している各アプリのフォルダには入りません。
 3. オフライン保存は、アプリのHTMLを端末に保存します。外部の文字や
    アイコンは、通信できないと表示されないことがあります。機内モードで一度ためしてください。
 4. 更新情報を足したあとは、tool/feed_koushin.bat を実行すると feed.xml が新しくなります。
    トップの「最新のお知らせ」は、koushin.html を読んで自動で更新されます。
 5. tool/sitemap_lastmod.bat は、サイトのフォルダで実行すると、sitemap.xml の更新日を
    実際のファイルの更新日にそろえます（元のファイルは .bak に残ります）。
 6. 多言語（英語・中国語・韓国語・モンゴル語）は、今回は入っていません。
