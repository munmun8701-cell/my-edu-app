【季節のかざり（トップページ）】
 すでにあったハロウィン・クリスマス・お正月・バレンタイン・お花見・七夕・夏休みに、次を追加しました。
   年末(12/26-30)・雪の季節(1/8-2/6)・年度の終わり(3/1-3/24)・ゴールデンウィーク(4/26-30)・
   こどもの日(5/1-6)・梅雨(6/1-30)・お月見(9/10-30)・紅葉(11/1-30)
 クリスマスは、イルミネーション・雪に加えて、ツリーとサンタのそりが出ます。
 期間は index.html の MUN_EVENTS で変えられます。
 試し見：設定の「季節の見た目をためす」で選ぶか、URLの最後に ?event=christmas などを付けます
   （christmas / kodomo / golden / nendo / fuyu / tsuyu / tsukimi / koyo / nenmatsu / newyear / halloween など）。
 期間限定アイテムが買えるのは、本当の期間中だけです（今までどおり）。
