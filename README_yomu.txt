アプリ説明の表示を直しました（更新 1112a）
=====================================
【直したこと】
 各アプリの下に出ていた「このアプリについて（保護者・先生の方へ）」の大きな黒い枠が、
 アプリの画面にはみ出して、レイアウトをこわしていました。
 今回から、画面のすみ（右下）に小さな「📘」ボタンだけが出て、おすとフロートで説明が開きます。
 アプリの画面の広さや配置には、いっさい影響しません。印刷のときは表示されません。
 （説明の文章は、検索エンジンが読めるよう、ページの中に残っています）

【やり方】
 1. このZIPの3つのファイル（mq_about_data.json / add_app_about.ps1 / setsumei_tsuika.bat）を、
    いつものように、トップページの index.html と同じフォルダに置く（上書き）。
 2. setsumei_tsuika.bat をダブルクリック。
    → 前に入れた説明は、新しい小さなボタン版に自動で置きかわります（何回実行しても大丈夫）。
 3. いつもどおりアップロード。
