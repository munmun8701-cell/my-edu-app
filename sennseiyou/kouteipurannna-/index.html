校庭プランナー運動会の配置図を、かんたんに
1テンプレート・図面名

運動会の定番配置から始めると、あとは備品を動かすだけです。

テンプレートを選ぶと、今の備品が入れ替わります（「戻す」で元に戻せます）。

2校庭の形

角は図の上でドラッグしても動かせます。

3トラック

作ったトラックは下の一覧で切り替えられます。案を何通りでも比べられます。

位置・向き（ふだんは変えません）
4徒競走（スタート・ゴール）

図の青いゴールの線は、ドラッグでも動かせます。

5備品を置く

ボタンを押すと図の真ん中に置かれます。ドラッグで動かしてください。

同じ備品を等間隔に並べる
6距離を測る

図の上を2回クリックすると、その間の距離が出ます。レーンに沿うときは、クリックした場所のレーンを自動で選びます。

7材料・チェック
8置いた備品

　名前を押すと、その備品を選べます。

9ファイル

データはこのブラウザに自動保存されます。別のパソコンで続けるときは、ファイルに保存して開いてください。

備品の設定

使い方

作る順番：①テンプレートを選ぶ → ②校庭とトラックを合わせる → ③備品を置いて動かす → ④徒競走の位置を決める → ⑤距離を測って確かめる → ⑥印刷。

図の上で操作
備品をクリック選ぶ（Shiftを押しながらで複数選択）
備品をドラッグ動かす（近い備品の中心や角に、ぴたっと合います）
何もない所をドラッグ図を動かす（Spaceを押しながらでも可）
Shift＋何もない所をドラッグ範囲で選ぶ
選んだ備品の四隅の□ドラッグで大きさを変える
青いゴールの線ドラッグでゴールを動かす（スタートも自動で動く）
ホイール拡大・縮小
キーはたらき
Ctrl＋Z / Y戻す / やり直す
Ctrl＋C / V / Dコピー / 貼り付け / 複製
Delete選んだ備品を消す
←↑→↓選んだ備品を少しずつ動かす（Shiftで大きく）
V / M / P選ぶ / 距離を測る / 等間隔に並べる
Esc途中の操作をやめる・選択をはずす

0m地点は、トラックの上の直線の右はし（右のカーブの始まり）です。スタート位置は、0m地点から走る向きに測った数字です。距離の測り方は、レーンの内側の白線に沿って測ります。

以前のバージョンで保存したデータも、そのまま開けます。
