算数用語集（ことば辞典）

算数では、「商」「約数」「底面積」のように、ふだんの生活ではあまり使わないことばがたくさん出てきます。ことばの意味があいまいなままだと、問題文を読んでも何を聞かれているのかがわからなくなってしまいます。この用語集では、小学校の算数に出てくる大切なことば58こを、学年ごとに、意味と例を使ってやさしく解説しています。くわしい考え方は、各ことばのリンクから学習ガイドで確かめてください。

学年からさがす
1年生3年生4年生5年生6年生

1年生で学ぶことば

0（れい）（れい）

1つもないことを表す数です。

例お皿にりんごが1つもないとき、りんごの数は0こです。

「なかまづくりとかず」の学習ガイドへ →
1対1対応（いちたいいちたいおう）

2つのなかまのものを、1つずつ線でむすんでくらべる方法です。どちらが多いかが数えなくてもわかります。

例うさぎ4ひきとにんじん6本をむすぶと、にんじんが2本あまるので、にんじんのほうが多いとわかります。

「なかまづくりとかず」の学習ガイドへ →

3年生で学ぶことば

わり算（わりざん）

同じ数ずつ分けるときの計算です。「÷」の記号を使います。

例12このあめを3人で同じ数ずつ分けると、12÷3＝4で1人4こです。

「わり算」の学習ガイドへ →
商（しょう）

わり算の答えのことです。

例15÷3＝5 の「5」が商です。

「わり算」の学習ガイドへ →
あまり（あまり）

わり算で、分けきれずにのこった数です。あまりは、わる数より小さくなります。

例14÷4＝3あまり2 の「2」があまりです。

「わり算 2（あまりのあるわり算）」の学習ガイドへ →
たしかめ算（たしかめざん）

答えが正しいかを、別の計算で確かめることです。わり算では「わる数×商＋あまり＝わられる数」で確かめます。

例14÷4＝3あまり2 は、4×3＋2＝14 で確かめられます。

「わり算 2（あまりのあるわり算）」の学習ガイドへ →
時刻と時間（じこくとじかん）

「時刻」は「8時30分」のようなある時点、「時間」は「30分間」のような長さのことです。

例8時から8時30分までの時間は30分です。

「時計と時間」の学習ガイドへ →
筆算（ひっさん）

位をたてにそろえて書き、一の位から順に計算する方法です。

例468＋357 を筆算で計算すると825です。

「大きな数」の学習ガイドへ →
くり上がり・くり下がり（くりあがり・くりさがり）

たし算で10をこえたら上の位に1をうつすのがくり上がり、ひき算でひけないときに上の位から1をかりるのがくり下がりです。

例28＋5 は、一の位が13になるので1くり上がって33です。

「大きな数」の学習ガイドへ →
道のりときょり（みちのりときょり）

道にそってはかった長さが道のり、まっすぐにはかった長さがきょりです。

例家から学校まで、道を通ると1km200m（道のり）、まっすぐだと900m（きょり）。

「きょりと長さ」の学習ガイドへ →
ぼうグラフ（ぼうぐらふ）

数の大きさを、ぼうの長さで表したグラフです。大小をくらべるのに向いています。

例好きなくだものの人数をくらべるときに使います。

「表とグラフ」の学習ガイドへ →
目もり（めもり）

グラフやはかりで、大きさを読みとるためのしるしです。1目もりがいくつかを最初に確かめます。

例1目もりが2人のグラフで、5目もりなら10人です。

「表とグラフ」の学習ガイドへ →
暗算（あんざん）

筆算を使わずに、頭の中で計算することです。上の位から計算したり、きりのよい数にしたりする工夫があります。

例29＋47 は、30＋47＝77 から1をひいて76。

「暗算で計算しよう」の学習ガイドへ →
一万（いちまん）

千を10こ集めた数です。10000と書きます。

例一万を10こ集めると十万になります。

「10000より大きい数」の学習ガイドへ →
分数（ぶんすう）

もとの大きさを同じ大きさに分けたいくつ分かを表す数です。線の下が分母、上が分子です。

例1mを3等分した1つ分は1/3mです。

「分数を使った数の表し方」の学習ガイドへ →
分母・分子（ぶんぼ・ぶんし）

分数の線の下の数が分母（いくつに分けたか）、上の数が分子（そのいくつ分か）です。

例3/4 の分母は4、分子は3です。

「分数を使った数の表し方」の学習ガイドへ →
小数・小数点（しょうすう・しょうすうてん）

1より小さいはしたを、0.1のように表す数が小数です。「.」を小数点といいます。

例1Lと0.4Lで1.4Lです。

「数の表し方（小数）」の学習ガイドへ →
□を使った式（しかくをつかったしき）

わからない数を□として、お話の順番どおりに表した式です。

例□＋8＝23 の□は15です。

「□を使った計算」の学習ガイドへ →
倍（ばい）

ある大きさを1つ分としたとき、そのいくつ分かを表す言い方です。

例6cmの3倍は18cmです。

「倍の計算」の学習ガイドへ →
円・中心・半径・直径（えん・ちゅうしん・はんけい・ちょっけい）

ある点（中心）から同じ長さの点を集めた形が円です。中心から円までの長さが半径、中心を通るはしからはしまでの長さが直径で、直径は半径の2倍です。

例半径4cmの円の直径は8cmです。

「丸い形を調べよう（円と球）」の学習ガイドへ →
球（きゅう）

どこから見ても円に見える形です。ボールのような形です。

例ボールを半分に切った切り口は円になります。

「丸い形を調べよう（円と球）」の学習ガイドへ →
二等辺三角形・正三角形（にとうへんさんかくけい・せいさんかくけい）

2つの辺の長さが等しい三角形が二等辺三角形、3つの辺の長さがすべて等しい三角形が正三角形です。

例辺の長さが4cm・4cm・6cmの三角形は二等辺三角形です。

「三角形を調べよう」の学習ガイドへ →
角（かく）

1つの点から出ている2本の辺がつくる形です。辺の開きぐあいを角の大きさといいます。

例三角じょうぎには直角の角があります。

「三角形を調べよう」の学習ガイドへ →

4年生で学ぶことば

億・兆（おく・ちょう）

千万の10倍が一億、千億の10倍が一兆です。日本では4けたごとに「万」「億」「兆」と区切って読みます。

例1234億5678万 のように読みます。

「1億より大きい数」の学習ガイドへ →
折れ線グラフ（おれせんぐらふ）

点を線でつないで、時間とともに変わるようすを表すグラフです。線のかたむきが急なほど変わり方が大きいことを表します。

例1日の気温の変わり方を表すのに使います。

「グラフや表を使って考えよう」の学習ガイドへ →
度（°）（ど）

角の大きさを表す単位です。直角は90°、半回転は180°、1回転は360°です。

例三角じょうぎの角は90°・60°・30°です。

「角の大きさの表し方」の学習ガイドへ →
分度器（ぶんどき）

角の大きさをはかる道具です。中心を頂点に合わせ、0°の線を辺に重ねて読みます。

例分度器で角をはかると40°でした。

「角の大きさの表し方」の学習ガイドへ →
がい数（がいすう）

だいたいの数（およその数）のことです。

例38472人を、約38000人と表します。

「およその数の表し方と使い方」の学習ガイドへ →
四捨五入（ししゃごにゅう）

がい数にする位の1つ下の位の数字が0〜4なら切り捨て、5〜9なら切り上げる方法です。

例46375 を千の位までのがい数にすると46000です。

「およその数の表し方と使い方」の学習ガイドへ →
以上・以下・未満（いじょう・いか・みまん）

「以上」「以下」はその数をふくみ、「未満」はその数をふくみません。

例250以上350未満の整数は、250から349までです。

「およその数の表し方と使い方」の学習ガイドへ →
仮の商（かりのしょう）

2けたでわるわり算で、見当をつけてたてる商のことです。大きすぎたら1小さく、小さすぎたら1大きくします。

例91÷13 で仮の商9をたて、8、7と直して商は7です。

「わり算の筆算を考えよう（2けたでわるわり算）」の学習ガイドへ →

5年生で学ぶことば

体積（たいせき）

もののかさの大きさです。1辺1cmの立方体の体積を1cm³（立方センチメートル）といいます。

例たて3cm・横4cm・高さ2cmの直方体の体積は24cm³です。

「直方体や立方体の体積」の学習ガイドへ →
容積（ようせき）

入れものの内側の体積のことです。1L＝1000cm³です。

例内側が1辺10cmの立方体の入れものの容積は1Lです。

「直方体や立方体の体積」の学習ガイドへ →
比例（ひれい）

一方が2倍、3倍…になると、もう一方も2倍、3倍…になる関係です。

例えんぴつの本数と代金は比例します。

「比例」の学習ガイドへ →
合同（ごうどう）

形も大きさも同じで、ぴったり重なる2つの図形のことです。

例平行四辺形を対角線で分けた2つの三角形は合同です。

「合同な図形」の学習ガイドへ →
偶数・奇数（ぐうすう・きすう）

2でわり切れる整数が偶数、わり切れない整数が奇数です。0は偶数です。

例4、10は偶数、3、7は奇数です。

「偶数と奇数、倍数と約数」の学習ガイドへ →
倍数・公倍数・最小公倍数（ばいすう・こうばいすう・さいしょうこうばいすう）

ある数に整数をかけてできる数が倍数、2つの数に共通な倍数が公倍数、そのいちばん小さいものが最小公倍数です。

例3と4の最小公倍数は12です。

「偶数と奇数、倍数と約数」の学習ガイドへ →
約数・公約数・最大公約数（やくすう・こうやくすう・さいだいこうやくすう）

ある数をわり切ることができる整数が約数、2つの数に共通な約数が公約数、そのいちばん大きいものが最大公約数です。

例12と18の最大公約数は6です。

「偶数と奇数、倍数と約数」の学習ガイドへ →
約分（やくぶん）

分母と分子を公約数でわって、簡単な分数にすることです。

例12/18 を約分すると 2/3 です。

「分数のたし算とひき算」の学習ガイドへ →
通分（つうぶん）

分母のちがう分数を、大きさを変えずに分母が同じ分数になおすことです。

例1/2 と 1/3 を通分すると 3/6 と 2/6 です。

「分数のたし算とひき算」の学習ガイドへ →
仮分数・帯分数（かぶんすう・たいぶんすう）

分子が分母と同じか大きい分数が仮分数、整数と真分数の和で表した分数が帯分数です。

例7/4 は帯分数で 1と3/4 です。

「分数のたし算とひき算」の学習ガイドへ →
平均（へいきん）

いくつかの数量を、等しい大きさになるようにならしたものです。平均＝合計÷個数です。

例4、7、6、3 の平均は 20÷4＝5 です。

「平均」の学習ガイドへ →
単位量あたりの大きさ（たんいりょうあたりのおおきさ）

「1m²あたり」「1Lあたり」のように、1つ分あたりの大きさにそろえてくらべる考え方です。

例6m²に9人なら、1m²あたり1.5人です。

「単位量あたりの大きさ」の学習ガイドへ →
人口密度（じんこうみつど）

1km²あたりの人口のことです。人口÷面積（km²）で求めます。

例面積15km²に人口9000人なら、人口密度は600人です。

「単位量あたりの大きさ」の学習ガイドへ →
速さ（時速・分速・秒速）（はやさ）

単位時間あたりに進む道のりです。速さ＝道のり÷時間 で求めます。

例240kmを3時間で走る車の速さは時速80kmです。

「単位量あたりの大きさ」の学習ガイドへ →

6年生で学ぶことば

線対称・点対称（せんたいしょう・てんたいしょう）

1本の直線で折ると両側がぴったり重なる図形が線対称、1つの点を中心に180°回すともとの形に重なる図形が点対称です。

例正方形は線対称でも点対称でもあります。

「つり合いのとれた図形を調べよう（対称な図形）」の学習ガイドへ →
対称の軸・対称の中心（たいしょうのじく・たいしょうのちゅうしん）

線対称な図形の折り目の直線が対称の軸、点対称な図形の回転の中心が対称の中心です。

例正方形には対称の軸が4本あります。

「つり合いのとれた図形を調べよう（対称な図形）」の学習ガイドへ →
文字と式（もじとしき）

x や a などの文字を使って、数量の関係を表した式です。

例1本80円のえんぴつx本の代金は 80×x（円）です。

「文字と式」の学習ガイドへ →
逆数（ぎゃくすう）

2つの数をかけた積が1になるとき、一方をもう一方の逆数といいます。分数の分母と分子を入れかえた数です。

例3/4 の逆数は 4/3 です。

「分数をかける計算を考えよう」の学習ガイドへ →
比・比の値（ひ・ひのあたい）

2つの量の割合を a：b のように表したものが比、a÷b の値が比の値です。

例2：3 の比の値は 2/3 です。

「割合の表し方を調べよう（比）」の学習ガイドへ →
拡大図・縮図（かくだいず・しゅくず）

形を変えずに大きくした図が拡大図、小さくした図が縮図です。対応する辺の長さの比は等しく、対応する角の大きさは等しくなります。

例2倍の拡大図では、すべての辺が2倍になります。

「拡大図と縮図」の学習ガイドへ →
縮尺（しゅくしゃく）

実際の長さを縮めた割合のことです。1：25000 や 1/25000 のように表します。

例縮尺1：25000の地図で4cmは、実際には1kmです。

「拡大図と縮図」の学習ガイドへ →
代表値（平均値・中央値・最頻値）（だいひょうち）

データの特ちょうを1つの数で表した値です。平均値はならした値、中央値は大きさの順に並べたときの中央の値、最頻値は最も多く出てくる値です。

例3、5、5、6、8、9 の中央値は5.5、最頻値は5です。

「データの調べ方」の学習ガイドへ →
柱状グラフ（ヒストグラム）（ちゅうじょうぐらふ）

データを区間に分けて、それぞれの区間の個数（度数）を柱の高さで表したグラフです。

例50m走の記録を0.5秒ごとの区間に分けて表します。

「データの調べ方」の学習ガイドへ →
円周率（えんしゅうりつ）

円周の長さが直径の何倍かを表す数で、ふつう3.14を使います。

例直径10cmの円の円周は 10×3.14＝31.4cm です。

「円の面積」の学習ガイドへ →
底面積（ていめんせき）

角柱や円柱の底面の面積です。角柱・円柱の体積＝底面積×高さ です。

例底面積12cm²、高さ5cmの四角柱の体積は60cm³です。

「角柱と円柱の体積」の学習ガイドへ →
反比例（はんぴれい）

一方が2倍、3倍…になると、もう一方が1/2、1/3…になる関係です。x×y＝決まった数 で表せます。

例面積24cm²の長方形のたてと横は反比例します。

「比例と反比例」の学習ガイドへ →
樹形図（じゅけいず）

場合の数を、木の枝のように枝分かれさせて整理した図です。落ちや重なりなく調べられます。

例3人の並び方を樹形図にすると6通りです。

「並べ方と組み合わせ方」の学習ガイドへ →
